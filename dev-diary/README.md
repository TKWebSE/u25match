# 開発日誌

日々の開発進捗を記録するためのフォルダです。

## 使い方
- 日付ごとにMarkdownファイルを作成（例: `2025-10-31.md`）
- 今日やったこと、できたこと、できなかったことを記録
- 良かったこと、悪かったことを振り返る
- 明日やることを明記して次回の開発に繋げる

## フォルダ構成
```
app/dev-diary/
├── README.md           # このファイル
├── 2025-10-31.md      # 具体的な日誌
└── ...
```
